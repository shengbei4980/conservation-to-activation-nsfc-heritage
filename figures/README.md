Each figure directory separates `data/`, `code/`, and `outputs/`. `outputs/final/` contains submitted artwork; `outputs/script_reference/` contains archived script outputs where available. ## Run

The tested Python runtime is 3.11.7 with the versions in [requirements.txt](requirements.txt). Install them in your own environment, then use the commands in the relevant figure README:

```text
python -m pip install -r figures/requirements.txt
python figures/figure3/code/figure3_object_problem_method_sankey.py
```

Scripts resolve inputs relative to their figure directory and write regenerated files under ignored `outputs/reproduced/`. Upstream programs default to the existing raw tables in the repository's root `data/`; `DATA_DIR` can override the input directory. The font settings are preserved, so installed fonts can affect appearance.

Figure 1 uses Node.js and `@oai/artifact-tool` (tested 2.8.99) rather than the Python packages. Its original package.json does not install that runtime. The editable submitted PPTX is included for use without that package. Dependency environments, node_modules, bytecode caches and new test outputs are excluded from Git.

## Interpretation and traceability

The submitted files include manual edits and panel assembly. Figure 1's final PPTX is not generated byte for byte by the archived script. Figure 6 has a documented legend/unit discrepancy; Figure 7's submitted view contains six categories/141 projects versus seven categories/142 projects in the full data and original program. These are explicit source/display differences, not full reproduction passes. Details appear in each figure README.

- [Figure index](../metadata/figure_index.csv): manuscript numbering, code, inputs, artwork and status.
- [File manifest](../metadata/figure_file_manifest.csv): all 244 original files, English paths and source/destination SHA-256 values.
- [Duplicate-file mapping](../metadata/figure_duplicate_files.csv): 24 top-level duplicates retained once inside their figure directories.
- [Offline verification](verification.md): checks on the adapted publication copy.

The original raw-data collection and 144 report-text JSON files remain in root `data/`. The report-page image archives remain in [Release v1.0.0](https://github.com/shengbei4980/conservation-to-activation-nsfc-heritage/releases/tag/v1.0.0).
